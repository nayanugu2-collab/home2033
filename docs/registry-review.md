## 매칭 원칙

API 응답의 sggCd·umdCd를 붙인 10자리 법정동 코드와 umdNm을 모두 대조합니다. 후보 명부의 정확한 별칭과 주소가 일치해야 합니다. 숫자와 '단지'는 제거하지 않으며 이름 부분 일치로 연결하지 않습니다. 도로명 대체는 지번이 BL- 등으로 비어 있거나, 근거가 있는 구 지번인 경우에만 허용합니다. 이름이 비슷하거나 주소가 없는 거래를 자동 승인하지 않습니다.

수집 JSON에는 매칭한 complexId, 실제 API 명칭, 법정동 코드·명칭, 지번, 도로명, 전용면적, 거래일, 층, 거래유형, aptSeq를 남깁니다. 공개 정보가 동일한 별개의 계약을 임의로 하나로 줄이지 않습니다. 명부는 각 지역의 모든 대단지를 전수 수록한 것은 아닙니다.
