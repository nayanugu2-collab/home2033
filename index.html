주소와 면적까지 확인

10자리 법정동 코드, 법정동명, 명시된 단지명 별칭, 지번 또는 검증된 도로명과 건물번호를 확인합니다. 모호한 거래는 제외합니다.

최근 10건 평균으로 비교

기본값은 기준 주택 59㎡급과 비교 단지의 최근 10건 산술평균입니다. 10건 미만이면 있는 거래만 사용합니다. 최근 1건·3개월·6개월 중앙값 선택 시 기준 주택은 최근 1건이며, 최초 매수가는 참고 정보입니다.

면적·평균·중앙값·같은 날 거래 처리 기준

59㎡급은 58 이상 60 미만, 74㎡급은 73 이상 75 미만, 84㎡급은 83 이상 85.01 미만입니다. 공급평형과 다릅니다. 상세 화면에서는 정확한 전용면적 타입을 선택할 수 있습니다. 최근 10건 평균은 최근 12개월 내 해당 단지·선택 면적의 거래를 계약일 내림차순으로 최대 10건 골라 가격 합계를 건수로 나눈 산술평균입니다. 거래가 없으면 가격을 비웁니다. 같은 계약일은 거래 ID 사전순으로 정렬하므로 10번째 경계가 같은 날이면 ID 순으로 포함하며 실제 계약 순서를 뜻하지 않습니다. 3·6개월은 한국 날짜에서 각각 해당 개월을 뺀 다음 날부터 오늘까지이며, 짝수 건의 중앙값은 가운데 두 가격의 평균입니다. 같은 계약일에 여러 건이면 거래 ID 사전순 첫 건을 최근 1건으로 표시하고 동률 건수를 안내합니다. 면적급 전체 집계에는 같은 급의 타입이 함께 포함됩니다.
